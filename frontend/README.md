# EduVibe Frontend

Educational platform with admin and learner dashboards.

## Tech Stack

- React 19 (Vite)
- TypeScript
- Tailwind CSS 4
- Zustand (State Management)
- GSAP (Animations)
- Recharts (Charts)
- React Router (Routing)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

├── src/
│   ├── components/     # Shared UI components

## Features

### Admin Dashboard
- Manage lessons (CRUD operations)
- User management
- Analytics and insights
- Content filtering and search

### Learner Dashboard
- Browse and search lessons
- AI-powered recommendations
- Progress tracking (to be integrated)
- Lesson viewing with video/interactive content support

## Design Theme

- Primary Color: Sky Blue (#87CEEB)
- Background: Pure White (#FFFFFF)
- Style: Minimalist, typography-driven, fluid layouts
